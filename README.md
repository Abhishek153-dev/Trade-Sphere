# Trade-Sphere 🚀

A full-stack MERN Zerodha Clone trading dashboard built using React, Node.js, Express, and MongoDB.

## 🌐 Live Features

- User Authentication (Login / Signup)
- Dashboard UI
- Holdings Section
- Positions Section
- Funds Management
- Watchlist
- Responsive Design
- Real-time Styled Trading Interface
- REST API Integration
- MongoDB Database Connection

---

# 🛠️ Tech Stack

## Frontend
- React.js
- React Router DOM
- Bootstrap
- CSS

## Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcryptjs

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/yourusername/Trade-Sphere.git
```

---

## 2️⃣ Install Frontend Dependencies

```bash
cd frontend
npm install
```

---

## 3️⃣ Install Backend Dependencies

```bash
cd ../Backend
npm install
```

---

# 🔑 Environment Variables

Create `.env` inside Backend folder:

```env
PORT=3002
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```

---

# ▶️ Run Backend

```bash
npm start
```

Backend runs on:

```bash
http://localhost:3002
```

---

# ▶️ Run Frontend

```bash
cd frontend
npm start
```

Frontend runs on:

```bash
http://localhost:3000
```
